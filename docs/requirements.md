\# 长租公寓小红书AI内容助手 - 需求文档

\## 功能清单

1\. 房源信息表单输入：户型：两室一厅，一室一厅、面积:47平，49平，52平，63平、租金：2775，2852，2916，3036，3850，3900、地段：靠近浦江万达，山钢和润两个商场场、地铁/配套：浦江线汇臻路地铁站、楼层:4-20、装修：精装修、房源亮点：绿地公园，中式园林

2\. 调用大模型，一次性生成3种风格小红书文案（自住温柔风 / 性价比省钱风 / 简约干净风）

3\. 自动生成小红书标签 #xxx

4\. 本地违禁词检测，标出违规词，给出替换建议

5\. 根据房源信息，自动生成ComfyUI文生图正向提示词、负面提示词

6\. 对接本地ComfyUI接口，自动生成配图

7\. 支持批量导入多条房源，批量生成全部内容

8\. 全部结果导出Excel表格，附带图片路径



\## 技术栈

Python + Streamlit + LLM API + pandas + ComfyUI本地API
